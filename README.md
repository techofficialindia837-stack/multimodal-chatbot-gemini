# Multi-Modal Chatbot (Text + Image)

## Overview
This project implements a multi-modal chatbot using Google Gemini AI that can process both text and image inputs.

## Features
- Text-based conversation
- Image understanding
- Multi-modal interaction

## Dataset
The dataset includes sample images and prompts used for testing the chatbot.

## Technologies Used
- Python
- Google Gemini AI
- PIL (Image Processing)

## How to Run
1. Install dependencies
2. Add API key
3. Run app.py

The chatbot can analyze images and respond to user queries.# multimodal-chatbot-gemini
